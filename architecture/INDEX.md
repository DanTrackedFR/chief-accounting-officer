## Core rule

`CAO Agent → Orchestration → Domains → Skills → Methods / Knowledge / Artifacts`

Domains organize the remit. Skills perform bounded capabilities. Standards and industries supply knowledge. Company Accounting Memory supplies company-specific truth and history. The CAO Agent synthesizes them into one coherent accounting work product.
