# Terminology and Normative Language

## Normative terms

- **MUST** — an absolute requirement of this architecture.
- **SHOULD** — the expected approach unless a documented reason justifies an alternative.
- **MAY** — an optional approach permitted by this architecture.

## Core terms

- **CAO Agent** — the single user-facing accounting agent.
- **Orchestration** — construction and execution of a task-specific workplan graph.
- **Domain** — an organizing area for related accounting capabilities; not an agent or workflow.
- **Skill** — a bounded capability that returns a structured result to orchestration.
- **Knowledge source** — principles, standards, practice, or company knowledge consumed by capabilities.
- **Artifact** — a source document or a finished accounting output.
- **Overlay** — framework, jurisdiction, industry, or company context that modifies capability execution.
- **Company Accounting Memory** — the five durable institutional knowledge stores.
- **Context Observer** — the internal end-of-task review that determines whether new information should be promoted to durable memory.
- **Workplan graph** — a dynamic task plan that can express dependencies, parallel work, iteration, and challenge.

Terms SHOULD be reused consistently. Contributors SHOULD avoid introducing synonyms that obscure these distinctions.
