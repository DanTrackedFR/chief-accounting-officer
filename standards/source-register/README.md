# Standards Source Register

Source metadata is governed by `knowledge/source-registry-schema.md`.

Initial active standard-setter families:
- IFRS Foundation / IASB — IFRS.
- Financial Accounting Standards Board — US GAAP.
- Financial Reporting Council — UK GAAP.
- Australian Accounting Standards Board — AASB.

The source register stores metadata and pointers, not restricted standards bodies of text.
