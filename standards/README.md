# Accounting Standards Knowledge

Standards are framework-specific knowledge sources consumed by CAO capabilities. They are not skills.

## Active Phase 2 frameworks

- IFRS
- US GAAP
- UK GAAP
- AASB

NZ IFRS is deferred and can be added later through the same framework contract.

Knowledge is built topic-by-topic across frameworks. The public repository stores independently authored CAO explanations, reasoning and implementation guidance with authoritative source pointers; it does not reproduce copyrighted standards text where rights have not been granted.

See [Knowledge Library Architecture](../architecture/knowledge-library-architecture.md).
