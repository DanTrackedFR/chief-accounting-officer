# Company Accounting Memory

This directory defines the five durable stores used by the CAO. These files are structural specifications only; they do not implement storage, application code, or database schemas.

- [Company Context](company-context.md)
- [Accounting Case Library](accounting-case-library.md)
- [Artifact Library](artifact-library.md)
- [Provenance / History](provenance-history.md)
- [Decision Register](decision-register.md)

All stores MUST preserve appropriate status, provenance, time, uncertainty, relationships, and supersession. Conversation history MUST NOT serve as institutional memory.
