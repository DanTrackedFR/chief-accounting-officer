# Context Promotion Rules

## Promotion gate

A candidate fact SHOULD enter durable memory when it is material, reusable, sufficiently supported, and likely to matter to another senior accountant in future unrelated work.

Promote:
- reporting framework, entity, currency, year-end, regulator and materiality facts;
- approved policies and recurring accounting positions;
- system architecture and durable process/control design;
- material accounting judgments with continuing relevance;
- implemented changes and the decisions that caused them;
- recurring known gaps and audit findings until resolved.

Normally keep case-level:
- one-off calculation inputs;
- temporary deadlines;
- draft ideas not adopted;
- immaterial conversational details;
- facts relevant only to one transaction unless precedent value exists.

## Conflict handling

A new candidate that conflicts with durable knowledge MUST create a conflict for resolution. It MUST NOT overwrite the existing record silently.

## Decision detection

Material language such as “we decided,” “going forward,” “from next month,” “we changed,” “instead of,” “management approved,” “audit asked,” or “implemented” SHOULD trigger a decision candidate. Materiality and durability still determine promotion.
