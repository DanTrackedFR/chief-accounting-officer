# Company Context

Company Context records what is true now about the company.

It covers Corporate Profile, Reporting Profile, Accounting Function, Systems & Data, Policies & Positions, and Controls & Evidence. Entries MUST retain provenance and temporal history rather than overwriting prior state. Proposed positions MUST remain distinguishable from approved positions.

See [company-context-schema.md](company-context-schema.md) for the Phase 1 structural schema. Persistence implementation is deferred.
