# Knowledge ID and Naming Conventions

## Topic IDs
`TOPIC-<DOMAIN>-<NNN>`, for example `TOPIC-04-001`.

Topic IDs are stable and framework-neutral.

## Knowledge record IDs
`KR-<TOPIC_ID>-<FRAMEWORK>-<NNN>`.

Framework codes: `PRINCIPLES`, `IFRS`, `USGAAP`, `UKGAAP`, `AASB`, `PRACTICE`.

## Difference IDs
`DIFF-<TOPIC_ID>-<NNN>`.

## Source IDs
`SRC-<PUBLISHER>-<NNN>`.

## Versioning
Stable ID identifies the conceptual record. Version tracks substantive evolution. Superseded versions remain traceable.

## File naming
Use lowercase kebab-case. File names describe the accounting issue, not a standard paragraph number. Framework references belong in record metadata.
