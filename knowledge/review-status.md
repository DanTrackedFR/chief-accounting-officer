# Knowledge Review Status

## Record statuses

DRAFT — research or authoring in progress.
REVIEWED — source/provenance and accounting logic reviewed against the build contract.
APPROVED — eligible for production CAO use under the project governance model.
SUPERSEDED — retained historically but not current for the relevant effective period.

## Completion

APPROVED knowledge records do not by themselves make a topic COMPLETE. Topic completion also requires framework coverage/N/A decisions, differences analysis, CAO execution logic, tests, QA, GitHub commit and Master Build Map update.
