# TOPIC-14-005 — Process Narrative / SOP / Control Documentation
Status: REVIEWED / production-candidate
Capabilities: CAO-14-013–015
Sensitivity: L

## Purpose
Document how accounting work actually flows from source event to ledger/reporting, not merely describe policy.

## Model
Policy -> Process -> System -> Control -> Accounting result -> Evidence.

## Required content
Purpose/scope; trigger/frequency; inputs/source systems; roles/RACI; numbered process steps; accounting decisions; interfaces; exceptions; journals; reconciliations; controls with owner/reviewer/evidence; outputs; retention; dependencies; escalation; change history.

Control documentation additionally states risk, assertion/objective, population, precision, frequency, performer/reviewer, evidence, exception treatment and IPE/system dependency.

## Practice
World-class narratives expose handoffs and failure points and link directly to system fields/reports and reconciliations. Screenshots alone are not procedures. A checklist without decision logic is not an SOP.

## QA
10/10 PASS across close, AP, AR, payroll, fixed assets, leases, intercompany, revenue, consolidation and reporting.
