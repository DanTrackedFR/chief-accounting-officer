# TOPIC-10-005 — Management Representation Support / Audit Findings & Management Letter Remediation

Status: REVIEWED / production-candidate
Capabilities: CAO-10-013, CAO-10-014
Sensitivity: L

## Management representation support
The CAO supports management representations by building a representation-evidence matrix rather than treating the letter as a ceremonial sign-off. For each accounting-related representation: identify responsible executive, underlying accounting evidence, exceptions/open matters, related memo/control, and whether facts remain current through signing.

The auditor determines the required representation letter under the applicable assurance regime. The CAO does not invent auditor wording or sign for management. Any representation management cannot support is escalated before signing.

## Findings remediation factory
1. Capture exact finding, source, date and affected process/account/control.
2. Separate symptom from root cause.
3. Determine accounting impact, control-deficiency implications and population potentially affected.
4. Define remediation with accountable owner, target date, system/process/control change and evidence of completion.
5. Define success criterion and post-implementation validation period.
6. Track interim mitigating action where final remediation is delayed.
7. Close only when design is implemented and evidence demonstrates the intended outcome; 'management agrees' is not closure.
8. Promote durable lessons into process/control/system documentation and Company Accounting Memory.

## Root-cause categories
Policy/knowledge; process design; unclear ownership; capacity/timing; system configuration; interface/data quality; access/segregation; review precision; evidence retention; change management; recurring manual workaround.

## Remediation quality
A strong action is specific, addresses root cause, has an owner/date, changes the operating model where needed, produces durable evidence and can be independently validated. Repeated manual review is not automatically an adequate response to a structural system/data problem.

## Controls
Finding register completeness; severity routing to Domain 09; overdue escalation; remediation-change approval; implementation evidence; independent closure review; repeat-finding flag; linkage to audit committee/governance reporting where applicable.

## Scenario tests
- Representation states all liabilities recorded but unresolved legal invoice population exists: flag exception and resolve/escalate before signing — PASS.
- Finding says reconciliation late; root cause is broken system interface: remediation addresses interface plus interim reconciliation, not just deadline reminder — PASS.
- New control documented but never operated: finding remains open — PASS.
- Repeat finding returns next year: elevate root-cause/governance assessment — PASS.

## Practice classification
This topic is primarily CAO practice and governance. Engagement-specific representation requirements are assurance-framework/jurisdiction dependent and must be sourced when invoked.
