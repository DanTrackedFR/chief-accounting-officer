# TOPIC-05-001 — Accounts Payable Accounting / AP Subledger-to-GL Reconciliation

Status: REVIEWED / production-candidate
Capabilities: CAO-05-001, CAO-05-002

Full knowledge factory: `factory.md`.

The topic treats AP as an accounting/control population rather than invoice processing. Recognition follows the underlying transaction; cut-off follows the economic event; the AP subledger must bridge reproducibly to the GL; and completeness procedures explicitly address missing invoices, GRNI, post-close invoices, debit balances, credits, manual control-account journals, FX and supplier-finance indicators.
