# Practice, controls and QA — TOPIC-13-012

## Practice model
Required: authoritative accounting conclusion, complete issue inventory, evidence trail, reconciled entries and reporting consequences.
Recommended: named issue owners/reviewers, decision log, specialist-input register, milestone calendar and pre-close dry run.
World-class: transaction data room linked to accounting case graph; automated source-to-model reconciliations; versioned assumptions; continuous issue-status dashboard.
Shortcut/risk: starting with journal entries before scope analysis; relying on legal labels; mixing frameworks; using unsigned term sheets as final facts; accepting valuation outputs without accounting challenge; losing transaction-date/effective-period control.

## Controls
Single approved fact base; contract completeness; framework/version check; specialist deliverable review; model version control; JE approval; disclosure tie-out; post-close true-up/measurement-period tracker where applicable; audit-evidence indexing.

## Scenario QA — PASS 10/10
1. Acquisition financed with debt/equity/earnout — decompose combination, financing, contingent consideration, transaction costs. PASS.
2. Divestiture with TSA and retained interest — separate disposal, continuing involvement, related-party/contract issues. PASS.
3. Debt-for-equity restructuring — route debt derecognition/modification plus equity classification. PASS.
4. Common-control reorganization — framework-specific gap/route rather than IFRS 3 assumption. PASS.
5. Carve-out before IPO — perimeter, allocation, reporting and regulatory dependencies. PASS.
6. Hyperinflationary acquisition target — sequence local restatement/FX and combination mechanics. PASS.
7. Multi-framework group — maintain separate framework conclusions and reconciliation. PASS.
8. Missing valuation — specify required valuation input and continue all non-blocked accounting workstreams. PASS.
9. Signed agreement changes before close — refresh fact base and affected issue nodes only. PASS.
10. Recurring transaction reconciliation across ERP/model/reporting — assess automation only where recurring cross-system workload justifies it. PASS.
