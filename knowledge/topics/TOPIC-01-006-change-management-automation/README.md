# TOPIC-01-006 — Accounting Change Management & Automation Opportunity Assessment

Status: **REVIEWED / production-candidate**
Capabilities: CAO-01-013, CAO-01-014
Knowledge type: PRINCIPLES / PRACTICE

## CAO execution logic
Treat accounting change as controlled process redesign. Define current state, accounting/control requirements and target outcome before selecting automation. Score opportunities on volume, determinism, data quality, exception rate, control risk, effort and recoverability. Automate repeatable mechanics while preserving human judgment and exception ownership. Pilot, parallel-run where risk warrants, measure and retire legacy steps only after acceptance.

## Required artifacts
Change impact assessment; automation opportunity register; business/control requirements; pilot and acceptance plan; exception/fallback design; benefits realization log.

## Controls and evidence
Changes have accountable owner, testing evidence and rollback. Automated outputs reconcile to source/GL as applicable. Access and change management are controlled. Benefits exclude unproven future savings.

## Scenario QA
PASS — deterministic reconciliation with clean inputs is automation candidate. PASS — policy judgment is decision support, not unattended automation. PASS — high exception rate requires root-cause work before automation.

## Framework/source routing
This is primarily controllership practice. Do not manufacture four-framework differences. Route recognition/measurement questions to the relevant technical topic. Statutory, listing, ICFR, audit, privacy and other jurisdiction-specific obligations require explicit jurisdiction and effective-period gating.
