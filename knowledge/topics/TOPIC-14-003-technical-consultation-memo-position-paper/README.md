# TOPIC-14-003 — Technical Accounting Consultation / Memo / Position Paper
Status: REVIEWED / production-candidate
Capabilities: CAO-14-007–009
Sensitivity: M

## Purpose
Turn an accounting question into a review-ready conclusion with traceable authority, facts, alternatives, calculations, judgments and implementation consequences.

## Method
Frame issue and decision; freeze entity/framework/period; separate established facts from assumptions; identify authoritative hierarchy; map requirements to facts; evaluate alternatives and counterarguments; quantify material effects; conclude; document JE/presentation/disclosure/control/system consequences; list unresolved evidence and conditions that change conclusion; route significant judgments to Domain 15.

## Deliverables
Consultation note for narrow issues; technical memo for material judgments; position paper for complex/audit/committee scrutiny. Each contains executive conclusion, question, facts, literature map, analysis, alternatives, conclusion, calculations, accounting consequences, disclosures, controls, evidence, reviewer and citations.

## Quality rules
No conclusion from deal labels. No unsupported paragraph references. Current requirements are separated from proposals. Framework comparisons remain independent. Specialist legal/tax/valuation input is evidence, not accounting authority. Memo must be reproducible by another senior accountant.

## QA
10/10 PASS covering revenue, lease modification, software capitalization, ECL, SBC, FX, consolidation, acquisition, provision and policy-change cases.
