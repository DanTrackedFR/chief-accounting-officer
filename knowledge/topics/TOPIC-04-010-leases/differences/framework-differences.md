# Leases — Framework Differences

Status: REVIEW CANDIDATE
Checked: 2026-09-22

| Issue | IFRS 16 | ASC 842 | FRS 102 (2026+) | AASB 16 |
|---|---|---|---|---|
| Lessee model | Single ROU/liability model subject to exemptions | ROU/liability but finance vs operating classification retained | Revised on-balance-sheet model based on IFRS 16 principles with UK simplifications | Closely aligned to IFRS 16, Australian overlays |
| Expense pattern | Depreciation + interest | Finance: amortization + interest; operating: single lease cost generally straight-line | Apply revised Section 20 mechanics; do not assume IFRS identity | Generally IFRS-aligned |
| Low-value | Explicit exemption | No equivalent general low-value exemption | FRS 102-specific exemption/simplification | IFRS-aligned core |
| Short-term | Election/exemption | Election | Exemption in revised model | IFRS-aligned core |
| Discount rate | Implicit if readily determinable, otherwise IBR | Topic 842 model; eligible nonpublic entities can elect risk-free rate by asset class | FRS 102 simplifications; use current Section 20 | Generally IFRS-aligned |
| Lessee classification | No operating/finance split for ordinary lessee recognition | Finance vs operating | Old lessee split replaced for most leases | Generally IFRS-aligned |
| Lessor | Finance / operating | Sales-type / direct financing / operating | Separately specified Section 20 model | IFRS-aligned core |
| Effective-period risk | Current IFRS 16 + amendments | Topic 842 + amendments | HIGH: pre-2026 and 2026+ materially differ | Current 2026 compilation applies 2024–2026 periods |
| NFP/public sector | IFRS scope | US literature interactions | UK entity-regime context | Explicit Australian overlays |

Always resolve framework, entity type and reporting period before calculation. Cross-framework answers must explain accounting consequences, not merely list differences.
