# Lease Case Output Specification

A complete CAO lease case can produce:
- executive conclusion;
- lease-identification assessment;
- lease-term/options paper;
- component/election decision;
- payment population;
- discount-rate paper;
- initial measurement schedule;
- subsequent rollforward;
- modification/reassessment calculation;
- journal-entry pack;
- lease-system-to-GL reconciliation;
- disclosure support;
- control/evidence checklist;
- technical accounting memo where judgment/materiality warrants.

Each output carries entity, framework, reporting period, contract ID, source documents, preparer/reviewer status, open items and provenance.
