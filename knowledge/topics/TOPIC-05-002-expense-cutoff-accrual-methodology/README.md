# TOPIC-05-002 — Expense Recognition & Cut-Off / Accrued Expense Methodology

Status: REVIEWED / production-candidate
Capabilities: CAO-05-003, CAO-05-004

Full knowledge factory: `factory.md`.

Key design rule: invoice timing does not determine expense timing, and 'matching' is not a standalone basis to create balance-sheet assets. The CAO establishes the underlying economic event/obligation, routes specialized transactions to their accounting topic, estimates unbilled obligations from the strongest available evidence, prevents duplicate recognition, and back-tests the method.
