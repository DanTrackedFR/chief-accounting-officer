# TOPIC-14-002 — Framework Comparison / Guidance-to-Facts / Alternative Treatments
Status: REVIEWED / production-candidate
Capabilities: CAO-14-004, CAO-14-005, CAO-14-006
Sensitivity: M
Source checked: 2026-09-25

## Purpose
Compare accounting frameworks without collapsing genuine differences, apply guidance to evidence, and evaluate permitted alternatives.

## Method
1. Freeze facts, entity, period, transaction and comparison purpose.
2. Resolve authoritative source/effective date independently for each framework.
3. Compare scope and definitions first; then recognition, measurement, classification, presentation, disclosure, transition and elections.
4. Distinguish true framework difference from different fact assumptions.
5. Build a requirement matrix with source pointers and status.
6. Apply identical fact set to each framework and calculate consequences where relevant.
7. Identify permitted alternatives/elections, consistency requirements and transition.
8. Explain operational effects: COA, subledger, close, controls, disclosures, data and audit evidence.
9. Conclude separately under each framework; never create a synthetic “common GAAP”.

## Authority gates
IFRS: applicable Standards/Interpretations and IAS 8 policy hierarchy where no specific requirement exists. US: Codification is authoritative nongovernmental GAAP; ASUs communicate Codification changes but are not themselves authoritative. UK: operative FRS 102/FRC/company-law route. AASB: operative Australian standard independently verified, including entity/tier and AASB 18 effective-date routing.

## Artifacts
Facts matrix; framework-difference table; alternatives/elections register; calculation bridge; source register; recommendation memo; implementation delta.

## QA / scenarios
Same contract under IFRS/US; UK effective-date change; AASB entity-type gate; missing direct guidance; optional policy election; source conflict; secondary interpretation disagreement; changed fact assumption; pipeline amendment; immaterial difference.
Expected: independent authority, explicit differences, no framework borrowing. 10/10 PASS.
