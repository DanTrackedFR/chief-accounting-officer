# TOPIC-14-008 — Technical Documentation Quality Review / Citation & Evidence Traceability
Status: REVIEWED / production-candidate
Capabilities: CAO-14-020–021
Sensitivity: M

## Purpose
Provide the final quality gate for CAO technical artifacts.

## Review dimensions
Correct entity/framework/period; authoritative source hierarchy; current/effective guidance; facts supported; assumptions explicit; citations resolve to source and relevant proposition; requirements separated from interpretation/practice; calculations reproducible; alternatives addressed; judgments and uncertainty visible; accounting/disclosure/control consequences complete; evidence lineage intact; approvals/versioning present; durable memory candidates identified.

## Citation rules
Never invent paragraph numbers. Record source, standard/topic, paragraph where verified, URL/reference, source-check date, effective period and review status. A secondary source may explain but does not silently replace primary authority. Public-source limitations remain PARTIAL. Superseded guidance stays traceable.

## QA
A document cannot move to APPROVED merely because prose is polished. Failed source verification, unresolved effective-date routing, missing material evidence or non-reproducible calculations prevent approval.
