# TOPIC-01-002 — Ownership Design / Maturity Assessment / Transformation Roadmap
Capabilities: CAO-01-004, CAO-01-005, CAO-01-006
Status: REVIEWED / production-candidate

## Objective
Turn accounting responsibilities and maturity gaps into an executable transformation roadmap.

## Ownership model
For every material process define one accountable owner, responsible operator, reviewer/control owner, consulted specialist and informed stakeholders. Multiple accountable owners or an absent required independent reviewer are design defects.

## Maturity assessment
Assess people/capability, process standardization, policy/judgment, close discipline, controls/evidence, systems/integration, data quality/lineage, reporting/disclosures, audit readiness and change capacity. Score observable evidence rather than perceived sophistication.

Suggested 1–5 anchors: 1 ad hoc/key-person; 2 repeatable but manual/inconsistent; 3 documented/controlled; 4 standardized/automated with metrics; 5 scalable, monitored and continuously improved. Never average away a critical control or reporting weakness.

## Roadmap logic
1. Capture evidence and score dimensions.
2. Identify gaps against the company's next 12–24 month obligations, not an abstract world-class target.
3. Prioritize mandatory reporting/control failures, then close/data bottlenecks, then scale/economics.
4. Sequence prerequisites: policy/process, then data/control, then automation.
5. Define work packages with owner, outcome, dependency, effort, risk, milestone and acceptance test.
6. Protect BAU capacity and create explicit transition controls.
7. Reassess after acquisitions, system implementations, financing/public-company milestones or major product/geography expansion.

## Artifacts
Responsibility matrix; maturity evidence matrix; heatmap; target-state gap register; dependency graph; 90-day/12-month roadmap; benefits register; acceptance criteria.

## Scenario QA
PASS — undocumented close cannot score as controlled merely because it is fast.
PASS — IPO target elevates controls, disclosure and evidence gaps above convenience automation.
PASS — ERP migration is not transformation completion without process/data/control acceptance tests.
PASS — a severe segregation issue remains red even when average maturity is high.
PASS — roadmap reserves BAU and transition-control capacity.
