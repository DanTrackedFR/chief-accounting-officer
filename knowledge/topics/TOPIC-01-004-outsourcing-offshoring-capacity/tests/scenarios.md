# Scenario QA — TOPIC-01-004

Executed 2026-09-27 against the canonical topic decision logic.

1. **Stable high-volume AP processing proposed for external provider** — PASS only if policy, approval, exception ownership, access, reconciliation, evidence, SLA/quality and retained-accountability controls are defined.
2. **Revenue process has 18% unresolved exceptions and undocumented judgment rules** — PASS: do not lift-and-shift; stabilize policy, data, workflow and exception taxonomy before sourcing.
3. **One technical-accounting specialist owns all complex transactions** — PASS: capacity model identifies concentration risk and requires documented backup/coverage rather than treating average utilization as adequate.
4. **Provider meets ticket SLA but month-end reconciliation breaks increase** — PASS: accounting quality and downstream control metrics override throughput SLA.
5. **Growth plan doubles entities without doubling transaction volume** — PASS: capacity model separately evaluates entity/statutory, close, consolidation, audit and judgment workload; transaction count alone is insufficient.
6. **Automation removes preparation effort but exceptions require more reviewer time** — PASS: savings are recognized only from observed end-to-end effort after stabilization.
7. **Offshore team receives privileged ERP access to solve turnaround issues** — PASS: access design must preserve least privilege and segregation; service speed does not override control design.
8. **Provider exit or outage occurs during close** — PASS: continuity plan identifies retained knowledge, data/evidence access, fallback operators and recovery reconciliation.

Result: **8/8 PASS**.
