# TOPIC-01-004 — Outsourcing, Offshoring & Capacity Planning

Status: **REVIEWED / production-candidate**
Capabilities: CAO-01-009, CAO-01-010
Knowledge type: PRINCIPLES / PRACTICE

## CAO execution logic
Build demand from recurring close work, transaction volume, reporting/audit peaks, projects and growth. Protect minimum review/control capacity and scarce technical skills. Classify work as retain, shared-service, outsource, automate or eliminate using judgment intensity, materiality, data sensitivity, exception rate and maturity. Model base and peak capacity; provider design must specify accounting ownership, evidence, access, incidents, change and exit.

## Required artifacts
Demand/capacity model; sourcing matrix; skill/key-person map; provider RACI and service specification; trigger-based hiring/contractor/automation plan.

## Controls and evidence
Management retains accounting accountability. Provider output gets risk-based review. Access, confidentiality, continuity and transition are controlled. Capacity assumptions are reconciled to actual demand.

## Scenario QA
PASS — high-volume stable AP can outsource with exception and reconciliation ownership. PASS — unresolved exception-heavy process must stabilize before offshoring. PASS — single technical expert is a resilience gap requiring backup.

## Framework/source routing
This is primarily controllership practice. Do not manufacture four-framework differences. Route recognition/measurement questions to the relevant technical topic. Statutory, listing, ICFR, audit, privacy and other jurisdiction-specific obligations require explicit jurisdiction and effective-period gating.
