# TOPIC-04-011 — Sale-and-Leaseback & Lease Reporting

Status: BUILDING — Phase 2C linked topic

## Sale-and-leaseback decision tree
1. Resolve framework/reporting period.
2. Identify seller-lessee and buyer-lessor.
3. Test whether transfer qualifies as a sale under the framework's applicable sale/revenue guidance.
4. If no sale, apply financing/failed-sale accounting required by framework.
5. If sale, measure retained right-of-use and gain/loss using framework-specific mechanics.
6. Evaluate off-market terms.
7. Build leaseback liability schedule and subsequent measurement.
8. Address amendments effective for reporting period.
9. Prepare entries, disclosures, reconciliation and memo.

IFRS/AASB require particular attention to the 2022/2024-effective Lease Liability in a Sale and Leaseback amendment. US GAAP sale-and-leaseback mechanics are not assumed identical. UK GAAP must use the reporting-period-appropriate Section 20/related guidance.

## Lease reporting/reconciliation
Reconcile opening liability + additions + interest + cash + remeasurements/modifications + disposals/FX = closing liability. Reconcile ROU asset separately. Tie recognized expense/cash/disclosures to source schedules and GL.
