# Testing readiness gate

**Regime first.** Record issuer/listing, filer status, management evaluation and auditor-attestation applicability, period and service-organization footprint. SEC Release 33-8810 supplies an acceptable risk-based route for applicable US issuer management evaluation; PCAOB AS 2201 governs applicable integrated audits. A voluntary readiness project does not acquire SOX attestation merely by naming its RCM “SOX.” Local law and assurance standards govern other entities.

**Risk-to-evidence map.** For every significant account/disclosure and relevant assertion, identify the risk, control ID, entity/location, owner, frequency, precise review criteria, full population, system and report dependencies, evidence artifact and exception owner. Confirm design by walkthrough from transaction initiation to reported figure, including manual adjustments and outsourced process interfaces. Preserve decisions excluding controls with a documented risk rationale.

**Dry run.** Reperform a selected month: obtain immutable population snapshot, trace selected items, inspect whether reviewer investigated variance beyond the stated threshold, and match approval timestamp to when the underlying report was available. A signature with no review attributes fails. Test automated blocking with a disallowed transaction and inspect access/change governance. For service-organization reports, map period/scope, exceptions, subservice carve-outs and complementary user controls to local evidence; bridge uncovered periods.

**Failure routing.** An incomplete sample universe or unvalidated IPE prevents a reliable operating conclusion. Identify affected controls, obtain alternative direct evidence if possible, evaluate deficiency and reporting impact through 09-007, and reperform after corrective change. Do not infer an auditor's sample size or rely on management's dry run as the external auditor's conclusion.

**Workpaper and systems.** Versioned scoping memo, RCM, walkthrough, IPE inventory, access/change dependencies, source-system extract/counts, testing attributes, exceptions, remediation and certification dashboard. Link each retained file to control ID, entity, period and report version. A process migration requires a new walkthrough and before/after control evaluation.

**Adverse case.** Outsourced payroll assurance covers January–September, excludes the subservice provider and requires user approval of master-data changes. A December conclusion based solely on the report FAILS: bridge Q4, assess carve-out risk and test the company's complementary approval. The failed user control enters deficiency evaluation.

References: [SEC Release 33-8810](https://www.sec.gov/rule-release/33-8810); [PCAOB AS 2201](https://pcaobus.org/oversight/standards/auditing-standards/details/AS2201).
