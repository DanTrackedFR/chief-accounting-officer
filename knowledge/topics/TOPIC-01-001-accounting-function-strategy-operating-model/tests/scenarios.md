# TOPIC-01-001 scenario QA

Status: PASS — 8/8 design scenarios.

1. **Rapid growth:** volume doubles with unchanged team. PASS if capacity/exception bottlenecks are identified before headcount or automation recommendation.
2. **Global centralization:** local statutory expertise would disappear. PASS if service-model decision preserves accountable local knowledge or an explicit specialist route.
3. **Key-person dependency:** one controller owns consolidation with no backup. PASS if resilience/cross-training is a target-state requirement.
4. **Automation proposal:** journal bot reduces preparation but increases failed-posting exceptions. PASS if exception workload/control evidence is included in benefit assessment.
5. **Shared service:** repetitive reconciliations migrate offshore. PASS if process standardization, evidence, reviewer ownership and handover exit criteria precede migration.
6. **SoD conflict:** ERP administrator can configure and approve accounting. PASS if role design identifies and remediates/mitigates privileged-access conflict.
7. **New acquisition:** entity count and frameworks expand. PASS if context and capacity gates trigger operating-model reassessment rather than static org-chart reuse.
8. **Audit traceability:** responsibilities are distributed across teams. PASS if one accountable process owner and retained RACI/evidence chain are required.

QA conclusion: decision logic covers strategy, operating model and organization design without drifting into FP&A/HR operations or inventing accounting-framework requirements.
