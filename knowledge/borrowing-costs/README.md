# Governed Borrowing Costs supplement

Namespace `SUPPLEMENTAL_BORROWING_COSTS` supplies substantive capitalization authority separately from canonical CIP routing. It does not create a canonical topic or expand TOPIC-04-003. The register contains 23 atomic decisions per framework, initially REVIEWED with PENDING independent approval. `retrieve` refuses unapproved, stale or malformed knowledge.

Supported proposed scope: 2026 reporting periods entirely within calendar 2026; one domestic conventional tangible construction project for own use; IFRS full for-profit, AASB Tier 1 for-profit, ordinary US GAAP, and full commercial FRS 102. Asset qualification, financing cost measurement, actual expenditures, reconciliations and independent case review remain required company evidence. The broader domain includes inventory, software and other qualifying assets but those routes are not implemented by this extension.

Direct assurance and production approval are separate. Read RESEARCH.md, FRAMEWORK-METHOD.md, standards-claims.json and the independently authored review before relying on this package. Run `python knowledge/borrowing-costs/validate_supplement.py` and `python -m unittest discover -s knowledge/borrowing-costs -p 'test_*.py'`.

UK support is full commercial FRS 102 only. FRS 101 and FRS 105 remain unsupported separate regimes.
