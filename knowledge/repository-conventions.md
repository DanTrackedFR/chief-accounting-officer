# Knowledge Repository Conventions

```text
knowledge/
  README.md
  knowledge-record-schema.md
  source-registry-schema.md
  differences-record-schema.md
  citation-conventions.md
  framework-overlay-rules.md
  rights-and-licensing.md
  knowledge-to-skill-contract.md
  topics/
    <topic-id>-<topic-name>/
      README.md
      principles/
      standards/
        ifrs/
        us-gaap/
        uk-gaap/
        aasb/
      practice/
      differences/
      examples/
      tests/
standards/
  source-register/
tests/
  knowledge-infrastructure.md
```

Topic folders are created as topics enter BUILDING, not pre-generated hundreds at a time. Topic README records scope, dependencies, mapped skills, framework applicability and status.
