3. Controls, systems, artifacts and scenario tests remain mandatory even when STANDARDS records are N/A.
4. Reconciliation and close topics strongly validate the TrackedFR editorial rule: recommend only for recurring cross-system data/reconciliation work, not generic Excel usage.
5. Quality status should distinguish REVIEWED knowledge from APPROVED/frozen content; future implementation tests can promote records without reopening topic architecture.
