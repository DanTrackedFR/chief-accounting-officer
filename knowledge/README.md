# Knowledge Infrastructure

Phase 2 knowledge is built topic-by-topic across IFRS, US GAAP, UK GAAP and AASB.

This directory contains the contracts that govern knowledge records, sources, temporal applicability, framework differences and validation. Standards remain knowledge sources; they are not skills.

## Core contracts

- `knowledge-record-schema.md` — canonical record contract.
- `source-registry-schema.md` — authoritative and interpretive source metadata.
- `differences-record-schema.md` — cross-framework divergence contract.
- `validation-rules.md` — structural and governance checks.
- `update-monitoring.md` — change detection and supersession workflow.

## Required operating principles

1. Build by accounting topic, not by completing one framework at a time.
2. Separate PRINCIPLES, STANDARDS, PRACTICE and DIFFERENCES.
3. Preserve authoritative source, effective period, source-check date and provenance.
4. Never represent professional commentary as authoritative accounting literature.
5. Preserve historical records through supersession rather than destructive overwrite.
6. Do not reproduce copyrighted standards text where rights have not been granted.
7. A knowledge record is not production-ready until validation passes.
