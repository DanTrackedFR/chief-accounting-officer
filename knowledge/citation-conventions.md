# Citation and Reference Conventions

## Purpose

CAO knowledge must allow a professional user to verify analysis against authoritative literature without turning the repository into a reproduction of restricted standards.

## Standards references

Use the standard/codification identifier plus the most precise paragraph, section or clause reference appropriate to the framework.

Examples of format only:
- `IFRS 16.26`
- `IAS 38.57`
- `ASC 842-20-30-1`
- `FRS 102 Section 20, paragraph <x>`
- `AASB 16.26`

Do not invent paragraph references. A reference is added only after source verification.

## Source links

Link to official publisher pages where practical. Do not use a secondary source as the authoritative link when a primary source is available.

## Quotations

Default: no direct standards quotations in open-source knowledge records. Independently explain the accounting and provide the source pointer. Any future quotation allowance must be explicitly supported by the source registry rights classification.

## Secondary interpretation

Professional guidance may support interpretation and implementation but must be labelled as interpretive and must not substitute for primary authority.
