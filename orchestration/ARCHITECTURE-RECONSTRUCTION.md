## Reconciliation of implemented and deferred contracts

* `production.assess_case` is the CAO entrypoint. It preserves knowledge, source,
  exact implementation and independent certification gates. Runtime cannot mint
  a reviewer signoff; only clearly labelled synthetic tests regenerate theirs.
* Metadata discovery must use production registry + SKILL.md, not copy 50 owners.
  Existing triggers are often generic and Hedge frontmatter is sparse. Fact input
  adapters and a bounded planner interface supply executable issue identification;
  unrestricted natural-language source extraction is not claimed.
* Native owner imports reexecute the original case and compare the whole actual
  result. Inventory additionally binds numerical semantic metrics to qualified
  original source costs and consumes each economic identity once.
* Governance retained a pre-promotion exclusion of Inventory. Removing that single
  stale exclusion enables actual native Analytics consumption without changing
  accounting recognition, certification or unavailable-owner exclusions.
* Public interface previously described only future integration. The new CAO
  runtime and CLI exercise the seven registered routes through public_record,
  with separate internal Case/evidence and curated public accounting outputs.
* Case, Company Context and artifact structures are aligned to existing memory
  schemas. Persistence remains deferred. Context Observer emits candidates;
  approved context and decision history are never automatically overwritten.
* Canonical/supplemental accounting knowledge is outside this change. Preserve
  157 approved topics, 347 mappings, 1,598 claims; Tax64 / Agriculture66 /
  Inventory228 / Derivatives100 / Insurance168. No Grants branch content imported.

This is a neutral integration workstream within the existing roadmap; it does not
introduce a new numbered phase or claim the final product/UI is complete.
