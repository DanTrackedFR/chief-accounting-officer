# Build3 release evidence

integrated-proof.json is generated only from new unfamiliar synthetic inputs with
explicit test-only native review. Original source bytes are retained base64 with
SHA256, dimensions, context snapshots, requests, source locations and calculations.
Original native result versions are represented by immutable-field hashes; superseded
state is separate. Production restored Cases retain full original native versions.

run_release.py executes every prior suite plus hosted and intelligence suites in
bounded separate subprocesses. release-regression.json records actual distinct test
IDs, statuses, durations, full-source hashes, log hashes and seven validators. Reruns
are not added. Historical reference artifacts are compared by their existing tests,
not regenerated by this release runner. Evidence cannot self-reference its containing
commit; exact immutable SHA and GitHub runs are recorded on PR46 after publication.
